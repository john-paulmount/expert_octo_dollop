## Project overview

This project analyses personal Spotify listening history to identify
listening patterns, genre preferences, and time‑based behaviour.

The project was completed as part of the Data Science degree at
BPP University.

---

## Data

Spotify Extended Streaming History provided via GDPR export.

---

## Methods

- Data cleaning in Python using pandas
- Exploratory analysis using seaborn and matplotlib
- Unsupervised learning using K‑means clustering

---

## Key findings

- Clear differences between weekday and weekend listening
- Strong correlation between time of day and genre choice
